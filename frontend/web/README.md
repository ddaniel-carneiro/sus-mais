# Sustenta+ Frontend

Interface web do sistema Sustenta+, desenvolvida utilizando React, TypeScript e Tailwind CSS.

## Tecnologias

* React
* TypeScript
* Vite
* Tailwind CSS

## Instalação

Instale as dependências:

```bash
npm install
```

ou

```bash
yarn install
```

## Execução

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

ou

```bash
yarn dev
```

A aplicação ficará disponível em:

```bash
http://localhost:5173
```

## Estrutura do Projeto

```text
src/
├── assets/
├── components/
├── pages/
├── routes/
├── services/
├── styles/
└── utils/
```

## Integração

O frontend consome os dados da API do backend do Sustenta+ através de requisições HTTP.
